# John Carlo Landayan Portfolio

A responsive, dependency-free portfolio built for GitHub Pages.

## Publish on GitHub Pages

1. Create a GitHub repository and upload the files in this folder.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)`, then save.

The site uses plain HTML, CSS, and JavaScript, so no build command is required.
